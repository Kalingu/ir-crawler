# IR Crawler Project

This repository contains the crawled web pages for my Information Retrieval project.

## Crawled Pages

All the downloaded pages are stored in the `CrawledPages` folder:  
[Browse CrawledPages](https://github.com/Kalingu/ir-crawler/tree/main/CrawledPages)

## Overview

- The crawler starts from a seed page and collects multiple pages from the same domain.
- The project also builds an inverted index (`inverted_index.json`) from the crawled pages.

## Note

This repo contains only the crawled pages to share the results. Other project files have been removed for clarity.
